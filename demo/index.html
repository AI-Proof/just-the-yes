What is real: role titles, organisations, locations and links come from the Volunteering Data Standard API (the dataset's metadata gives its licence as CC BY 4.0; listings are the named organisations' own). The API returned 614 activities within 8 km of central London on 24 September 2026; none had structured skills, requirements or times filled in, so fit here uses distance and keywords. Interest areas and the "online" option are guessed from each listing's text, so some are wrong. Proposing person-side fields is part of the project.

What is simulated: the Pod, the inbox, the reply and the access rules. The messages shown under "Solid messages" are the ones the proof of concept would write and send: a yes resource in the volunteer's Pod, an ActivityStreams Offer to the organisation's inbox (Linked Data Notifications), a read rule for one named coordinator (shown in WAC; the access model is still to be chosen), and the reply. The Offer names the volunteer's WebID, so the organisation can see their public profile card, but never the private details in their Pod. Reply promises and capacities are examples; in the pilot each organisation sets its own. None of these organisations has joined a pilot.
