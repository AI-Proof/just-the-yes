# Background

These two notes were written for job markets, where the idea behind Just the Yes started. They are not part of the volunteering proof of concept.

- `gmp-two-page-summary.pdf`: a two-page summary of the General Matchmaking Protocol, the longer design whose central rule Just the Yes tests.
- `what-should-k-be.pdf`: a working note with a small simulation of how many priority applications per month a market can honour. The simulation was built with an AI assistant; its parameters are illustrative, not calibrated.
