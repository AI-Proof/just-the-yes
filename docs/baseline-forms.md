# Baseline: what eight public volunteer application forms ask for

Compiled on 23 September 2026 with an AI assistant (Claude, by Anthropic), from the public forms linked below; every count can be checked against the linked form. This is a small, non-random sample, found through web search. It leans towards councils and towards roles with safeguarding duties (youth justice, adult social care, children), where some checks are legally required at some stage. It is a starting point for the pilot's measurement, not a survey of the sector.

## Why this matters for the design

The point is not that these checks are wrong. The point is timing and reach. Today they are asked of everyone, at the first step, and each form sends them to a different organisation. Buckinghamshire shows that the alternative already exists: it asks about convictions only once a candidate is shortlisted. In Just the Yes, the first message carries only what a role needs for a first reply. References and background checks happen once both sides want to go ahead, and only for roles that need them.
